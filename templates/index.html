How It Works

Understanding the neural network behind the predictions

Network Architecture
Input Layer
784 Neurons (28×28 pixels)
Each pixel value (0-255) normalized to [-1, 1]
Hidden Layer 1
128 Neurons + ReLU Activation
Learns basic features (edges, curves)
Hidden Layer 2
64 Neurons + ReLU Activation
Combines features into digit parts
Output Layer
10 Neurons (Digits 0-9)
Softmax gives probability for each digit
Key Concepts

The input layer receives the 28×28 pixel image flattened into 784 values. Each neuron represents one pixel's intensity. Before feeding to the network, pixel values (0-255) are normalized using MNIST statistics (mean=0.1307, std=0.3081) so the network trains faster.

Hidden layers are the "thinking" layers between input and output. Our network has two: 128 neurons then 64 neurons. Each neuron computes a weighted sum of all inputs from the previous layer, adds a bias, and applies an activation function. Early layers detect simple patterns (edges, lines); deeper layers combine these into complex shapes (loops, corners).

A neuron is the basic computing unit. It receives multiple inputs, multiplies each by a learned weight, sums them up, adds a bias term, and passes the result through an activation function. Think of it as a tiny decision-maker that "fires" when its weighted input exceeds a threshold.

Weights determine how important each input is to a neuron. Biases allow neurons to shift their activation threshold. During training, the network adjusts these ~109,000 parameters to minimize prediction errors. This is what "learning" means in a neural network.

ReLU (Rectified Linear Unit): f(x) = max(0, x). It outputs the input directly if positive, otherwise zero. This introduces non-linearity, allowing the network to learn complex patterns. Without activation functions, a neural network would just be a linear regression model, no matter how many layers.

Forward propagation is the process of passing input data through the network layer by layer to get a prediction. Each layer transforms the data: output = activation(weights × input + bias). The final output gives raw scores (logits) for each digit class.

CrossEntropyLoss measures how wrong the prediction is. It combines LogSoftmax and NLLLoss: it applies softmax to convert logits to probabilities, then computes negative log likelihood of the correct class. Lower loss = better predictions. The network's goal during training is to minimize this loss.

Backpropagation computes gradients of the loss with respect to each weight using the chain rule. It flows backward from output to input, telling each weight how to change to reduce error. The optimizer (Adam) then updates weights: weight = weight - learning_rate × gradient. This repeats for many epochs until convergence.

After training, for inference we only do forward propagation. The output logits are passed through Softmax to get probabilities summing to 1. The digit with highest probability is the prediction. Confidence is that probability × 100%. The network generalizes to new handwritten digits it never saw during training!

About This Project

Technical details and educational purpose

Pure PyTorch

Built from scratch using PyTorch tensors and autograd - no high-level APIs hiding the details.

Real MNIST Training

Trained on 60,000 MNIST training images, tested on 10,000 test images with ~98% accuracy.

CPU Optimized

Runs inference on CPU only - compatible with free hosting tiers (Render, Railway, etc.).

Visual Analytics

Training curves, confusion matrices, and probability distributions generated automatically.

Educational Value

This project demonstrates fundamental deep learning concepts in a complete, working application:

  • End-to-end ML pipeline: Data loading → Preprocessing → Training → Evaluation → Deployment
  • Neural network fundamentals: Forward/backward propagation, activation functions, loss functions, optimization
  • Production practices: Model serialization, inference optimization, error handling, input validation
  • Web integration: REST API design, frontend-backend communication, real-time UX
Disclaimer: This is an educational project for learning purposes. The model is a simple ANN (not a CNN) and achieves ~98% accuracy on MNIST. For production digit recognition, CNNs or transformer-based models would be more appropriate.
